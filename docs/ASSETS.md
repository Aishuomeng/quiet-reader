# 视觉素材来源

- `src/assets/standard.png`：本项目通过 OpenAI 图像生成工具生成的山湖背景；全窗口铺展，用作标准版场景。
- `src/assets/anime.png`：本项目通过 OpenAI 图像生成工具生成的原创二次元海边阳台背景；无现成动漫角色、商标或文字。
- `src/assets/icon.png` / `AppIcon.icns`：本项目创建的「阅」字应用图标。
- 科技版：由 CSS 网格和渐变组成。
- 摸鱼版：由 HTML / CSS 表格组成，表中内容为虚构示例。

二次元背景的制作描述：原创日系动画风格、海边阳台、远处平静的海、粉紫色晚霞与樱花枝；画面中部保持开阔供长篇文字叠加；精细环境插画、柔和光线、无人物、无文字、无水印。生成后按原图嵌入应用，无联网加载。
