# 静读 3.0 使用指南

## 开始阅读

1. 打开静读，点击「导入小说」，选择 TXT 文件，也可以把文件拖入窗口。
2. 点击「目录」选择章节；目录搜索同时匹配章节标题与正文。
3. 「书架」用于切换小说、导出备份、恢复备份。关闭应用后再次打开会恢复最近的阅读位置。

支持 TXT，暂不支持 EPUB / PDF、在线书源和跨设备自动同步。没有章节标题的文本会作为单章打开。TXT 单本限制 30 MB；空文件或无法识别的文本会被拒绝。

## 主题套装和外观

顶部显示当前套装名称，点击后选择标准、二次元、科技、摸鱼版。切换时载入该套装的推荐颜色、字体和背景，并清除上一次自定义背景选择，书籍、书签和进度不变。

「外观」里可调整字号（14–40）、行距（1.4–2.8）、正文宽度（35%–92%）、字体、颜色，以及背景缩放（100%–220%）、横纵位置、明暗、模糊和阅读面板浓度。拖动滑杆即可看到效果。窄窗口会自动压缩布局。

背景选项会随套装变化：标准版有山间、暮色、远海；二次元版有樱海、暮樱、月夜；科技版有深空、星云、极地。三套都支持纯色和个人背景。纯色模式会隐藏不适用的缩放、位置与模糊滑杆；摸鱼版直接显示表格阅读设置，不显示图片背景与透明度控件。「恢复本套默认」只重置当前套装。全屏由顶部「全屏」按钮控制；「专注」隐藏阅读工具栏，按 Esc 退出专注。

## 自动阅读

点击底部「自动滚动」开始，再点一次暂停。「外观」里可调速度。到达章节底部后自动续章，最后一章结束时停止。鼠标滚轮、触摸、点击阅读区、离开应用窗口会暂停滚动。

## 摸鱼版

切换到「摸鱼版 · 工作台」后，标题栏和窗口标题会改成工作台，正文以表格行呈现。点击顶部「隐藏正文」或按 Ctrl+Shift+X（Mac 用 ⌘+Shift+X）立即展示不含小说的示例工作表。再次按快捷键或点击「返回」恢复。

「视图选项」可勾选切换窗口时自动隐藏正文。该功能仅隐藏应用界面，不对文件进行加密，也不阻止系统截图。

## 快捷键

| 操作 | macOS | Windows |
| --- | --- | --- |
| 导入小说 | ⌘O | Ctrl+O |
| 打开书架 | ⌘B | Ctrl+B |
| 全屏 | Ctrl+⌘F | F11 |
| 隐藏 / 恢复正文（摸鱼版） | ⌘ShiftX | Ctrl+Shift+X |
| 自动滚动 / 暂停 | 空格 | 空格 |
| 上 / 下一章 | ← / → | ← / → |
| 专注 | F | F |
| 退出专注 / 暂停 | Esc | Esc |

在输入框、按钮或弹窗中，部分阅读快捷键不会触发，以免干扰输入。

## 保存、备份与迁移

书籍、设置、阅读位置保存在本机。macOS 原生版目录是 `~/Library/Application Support/QuietReader/`；Windows 是 `%APPDATA%\QuietReader\`。不要手动编辑正在使用的数据文件。

书架 →「导出备份」将书籍正文、进度、书签及设置保存为 JSON。备份含有小说全文，分享前请留意内容。另一台电脑选择「恢复备份」即可导入，现有书籍保留，相同书籍可能重复出现。

如出现保存失败提示，请先导出备份再退出。程序包和数据目录分开，替换程序包不会主动删除书架。
