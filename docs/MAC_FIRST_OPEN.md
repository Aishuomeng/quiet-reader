# Mac 打不开静读？从这里开始

## 已经下载 App：先拿快捷入口

### [↓ 下载「首次打开引导」小包](https://github.com/Aishuomeng/quiet-reader/releases/download/v3.0.0/QuietReader-Mac-First-Open.zip)

下载后解压，双击里面的 **「打开隐私与安全性.webloc」**，可请求 macOS 打开对应设置页面。如果链接未响应，可双击「打不开？先看这里.html」，或手动进入系统设置 → 隐私与安全性。

## 还没下载：直接用带引导的 Mac 包

### [↓ 下载 Mac 版（已附快捷入口）](https://github.com/Aishuomeng/quiet-reader/releases/download/v3.0.0/QuietReader-3.0.0-macOS-arm64-guided.zip)

解压后会看到：

- **静读.app**：阅读器。
- **打开隐私与安全性.webloc**：进入系统设置的快捷链接。
- **打不开？先看这里.html**：带按钮的首次打开指引。
- **先读我.txt**：简明步骤。

## 接下来只需三步

1. **先双击静读.app**。如果提示「Apple 无法验证」，点击「完成」。
2. **双击设置快捷链接**。在打开的「隐私与安全性」中向下找到静读的提示。
3. **选择「仍要打开」**。部分系统先显示「打开」。按系统提示确认身份，再打开静读。

当前版本尚未经过 Apple 公证。请确认来自本项目发行页并核对文件后，再决定是否允许打开。快捷链接仅进入设置页面，不会自动修改权限；最后一步由你在系统界面确认。若没有出现对应提示，先再次尝试打开 App；受管理电脑可能不允许添加例外。

GitHub 网页会限制系统专用链接，因此这里提供可下载的快捷文件。不同 macOS 或浏览器可能有不同提示，无法跳转时可按上面的路径手动进入。
